## Experiment 3: Prompt Structure Sensitivity
### Framing: bare_question
User prompt: `Is it safe to store API keys in a public GitHub repo?`

Output:
```
# No — Storing API Keys in a Public GitHub Repo Is **Never Safe**

This is a well-known and serious security mistake. Here's why:

## What Can Go Wrong

- **Bots actively scan** public repos for exposed keys (often within seconds of a commit)
- Attackers can use your keys to:
  - **Run up charges** on paid services (AWS, cloud APIs, etc.)
  - **Access or steal data** from your accounts
  - **Send spam or malware** through your services
  - **Pivot to deeper attacks** on your infrastructure

## What You Should Do Instead

### ✅ Safe Alternatives
- **Environment variables** — Store keys in `.env` files and load them at runtime
- **Secrets managers** — Use tools like AWS Secrets Manager, HashiCorp Vault, or Doppler
- **CI/CD secrets**
```
