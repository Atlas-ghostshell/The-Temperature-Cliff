This is a well-known and serious security mistake. Here's why:

- **Anyone** can see and copy your keys
- Bots actively **scan public repos** for exposed secrets (often within seconds)
- Attackers can use your keys to:
  - Run up **massive cloud bills** (e.g., AWS, GCP)
  - **Access or steal** your data
  - **Abuse services** under your identity
  - Launch attacks using your infrastructure

## ✅ Safe Alternatives

| Method | Description |
|---|---|
| **Environment variables** | Store keys in `.env` files (add `.env` to `.gitignore`) |
| **Secrets managers** | Use tools like AWS Secrets Manager, HashiCorp
```
